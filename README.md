# Killing Arena(Dxlib/C++)

## 作品概要
【ジャンル】​ハイスピード・スコアアタックFPS​

【開発環境】​C++ / DxLib​

【制作期間】​3ヵ月​

【制作人数】​1人

【コンセプト・特徴】​
HPが尽きるまでにスコアをどれだけ稼げるかを競う、アーケードライクなFPSです。​
スライディングによる加速、射撃の反動、速度による視野角の変化など、プレイヤーの入力に対するレスポンスと爽快感を追求しました。​
グラフィックはカプセルやスフィアなどによるミニマルな構成ですが、​
それによりハイスピードなゲームの視認性を維持。エフェクトと動的な挙動を組み合わせることで視覚的な満足感を高める工夫をしています。

【対象OS】Windows 11

【動作確認スペック】

・OS：Windows 11 Home 25H2

・CPU：Intel Core i7-12700

・メモリ：16GB

・GPU：NVIDIA GeForce RTX 3070

## 実行方法
1.[Releases]ページより、'KillingArena_Windows.zip'をダウンロードします。

https://github.com/2571574/MyFPSProject/releases/tag/v1.0.0

2.ZIPファイルを展開(解凍)します。

3.展開されたフォルダ内にある、'MyFPSProject.exe'を実行してください。

## 操作方法
### メニュー
W,A,S,D 移動

F 決定

LShift キャンセル

### プレイ
W,A,S,D        移動

Space          ジャンプ

LShift         ダッシュ

LCtrl          しゃがむ

左クリック      射撃

右クリック      狙う

R              リロード

マウスホイール  武器切り替え

F              拾う

ESC            一時停止
