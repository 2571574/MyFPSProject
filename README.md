# Killing Arena(Dxlib C++)

## 実行方法
1.[Releases]ページより、'KillingArena_Win.zip'をダウンロードします。

2.ZIPファイルを展開(解凍)します。

3.展開されたフォルダ内にある、'MyFPSProject.exe'を実行してください。

## 操作方法
### メニュー
W,A,S,D 移動

F 決定

LShift キャンセル

### プレイ
W,A,S,D        移動

Space          ジャンプ

LShift         ダッシュ

LCtrl          しゃがむ

左クリック      射撃

右クリック      狙う

R              リロード

マウスホイール  武器切り替え

F              拾う

ESC            一時停止

※ゲームパッドにも対応
ゲーム内でキーバインドの変更も可能です。
